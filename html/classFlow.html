Detailed Description

Interface que define um fluxo da simulação.

Um Flow representa uma transferência de valores entre dois sistemas. Possui um sistema de origem, um sistema de destino e uma equação responsável por calcular a taxa de transferência.

As classes concretas devem implementar o cálculo da equação.
