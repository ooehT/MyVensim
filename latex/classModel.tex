\doxysubsection{Detailed Description}
Interface que define um modelo de simulação. 

A classe \doxylink{classModel}{Model} representa a estrutura responsável por armazenar sistemas e fluxos, além de controlar a execução da simulação.

É uma interface abstrata que deve ser implementada por classes concretas.
